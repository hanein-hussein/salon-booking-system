# Salon Booking System

A web-based salon booking system built with PHP, MySQL, JavaScript, HTML, and CSS.

## Features
- Book appointments
- Search bookings
- Edit existing bookings
- Delete bookings
- Responsive design
- Modal popups for editing

## Technologies Used
- PHP
- MySQL
- JavaScript (Fetch API)
- HTML5
- CSS3

## Project Structure
- `index.html` – Home page
- `booking.php` – Booking form
- `reserve.php` – Save booking to database
- `search.php` – Search and manage bookings
- `edit.php` – Update booking
- `delete_booking.php` – Delete booking
- `db.php` – Database connection
- `css/style.css`
- `javascript/modal.js`

## Database Setup
1. Create a MySQL database.
2. Import the SQL file located in `database/salon_booking.sql`.

## Local Setup
1. Place the project folder inside `htdocs`.
2. Start Apache and MySQL in XAMPP.
3. Open:
   `http://localhost:8080/WEBSITE%20PROJECT/`
